Eu quero criar um aplicativo web para gerenciar minhas finanças pessoais.

O aplicativo deve ser capaz de:

# Transações

- Cadastrar, editar e excluir transações
- Cadastrar, editar e excluir categorias

## Fontes de renda

- Cadastrar, editar e excluir fontes de renda

## Fontes de despesa

- Cadastrar, editar e excluir fontes de despesa

# Analises

- Visualizar gráficos de receitas e despesas
- Visualizar gráficos de categorias
- Visualizar gráficos de fontes de renda
- Visualizar gráficos de fontes de despesa

# Importação de dados

- Importar dados de csv

# IA

- Gerar resumo das transações
- Gerar resumo das fontes de renda
- Gerar resumo das fontes de despesa

# Visualizações

- Gostaria de visualizar por mês, ano, dia, semana, etc.

Gostaria de uma forma de sempre excluir dados sigilosos, como senhas, números de cartões, cpf, etc.
